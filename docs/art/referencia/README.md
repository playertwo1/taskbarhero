## Uso destas imagens

- **DECIDIDO:** os IDs e nomes dos inimigos seguem o bestiário v0.4; as identidades visuais aprovadas dos Golden correspondentes permanecem fixas.
- **CANDIDATAS:** as novas referências dos inimigos são estudos visuais para revisão. O Guardião-Cervo v003 é candidato; o Golden v002 continua sendo a versão aprovada.
- **CONCEITO:** imagens novas servem para revisão visual e como referência inicial ao planejar sprites. Não determinam canvas, animação, atributos, comportamento nem aprovam alteração de ficha.
- Antes de produzir sprites, siga o contrato específico quando existir, os [Golden](../golden/README.md), a [paleta](../PALETTE.md), o [guia de estilo](../SPRITE_STYLE_GUIDE.md) e os gates do [roadmap](../../../ROADMAP.md).
