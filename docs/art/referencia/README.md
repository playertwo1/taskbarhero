## Uso destas imagens

- **DECIDIDO:** IDs, nomes e identidades visuais aprovadas dos Golden correspondentes seguem as fontes canônicas.
- **CANDIDATAS:** conceitos atuais servem para revisão visual; o Guardião-Cervo v003 é candidato e o Golden v002 continua aprovado.
- **CONCEITO:** imagens são referência inicial ao planejar sprites. Não determinam canvas, animação, atributos ou comportamento, nem aprovam alteração de ficha.
- Antes de produzir sprites, siga o contrato específico quando existir, os [Golden](../golden/README.md), a [paleta](../PALETTE.md), o [guia de estilo](../SPRITE_STYLE_GUIDE.md) e os gates do [roadmap](../../../ROADMAP.md).
