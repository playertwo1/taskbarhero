# Modelos conceituais — cinco heróis restantes

**Status:** CONCEPT SET SELECTED AS STYLE REFERENCE — Rafael aprovou este conjunto como base de apresentação dos modelos conceituais em 2026-09-28. Não são sprites finais, Golden nem aprovação de produção. Fichas e contratos individuais continuam sendo a autoridade do design.

- [Brasa](hero_brasa_model_concept_v001.png) — bruiser de machados, cabelo cor de brasa e armadura marcada por cinzas.
- [Véu](hero_veu_model_concept_v001.png) — assassina de capuz carvão, franja carmesim e adagas duplas.
- [Orvalho](hero_orvalho_model_concept_v001.png) — pequeno jardineiro de chapéu largo com broto, avental de sementes e regador rúnico.
- [Forja](hero_forja_model_concept_v001.png) — engenheira com óculos de latão, ferramentas, martelo-chave e sentinela rúnica.
- [Sino](hero_sino_model_concept_v001.png) — memorialista de túnica cerimonial e cajado de pequenos sinos de Lúmen.

As imagens foram geradas como conceitos isolados com base nas fichas e folhas atuais e na leitura pixelada do Golden de Bastião. Rafael escolheu o acabamento e formato como referência para futuros modelos conceituais; isso não congela cada desenho como modelo canônico. Consulte a [direção de modelos conceituais](../../CONCEPT_MODEL_STYLE.md), o [índice de heróis](../../../02_heroes/INDEX.md), [contratos de arte](../../contracts/) e [Golden](../../golden/README.md).
