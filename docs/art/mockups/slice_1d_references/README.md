## Limites e fontes

As imagens foram geradas com apoio do ImageGen e servem como referências de composição/UX e atmosfera. `v002` usa noite azul-negra, pedra gótica envelhecida, sombras profundas, brasas contidas e Lúmen verde-azulado. A tipografia rasterizada pode conter erros; reconstruir qualquer texto na UI real. Para produção, manter os requisitos de modularidade e QA da [direção visual do Refúgio](../../../05_hub/HUB_VISUAL_DIRECTION.md), além da [base visual](../../ASSET_VISUAL_BLUEPRINT.md), [guia de estilo](../../SPRITE_STYLE_GUIDE.md) e [paleta](../../PALETTE.md). A aparência das imagens não substitui pixel cleanup, contratos, auditoria visual ou validação mobile.
