# Revisão de Íris — modelo conceitual v003

**Status:** CONCEPT v003 — revisão solicitada por Rafael para diferenciar visualmente Íris de Sino.

[Ver Íris v003](hero_iris_model_concept_v003.png)

A revisão dá à Íris cabelo curto ameixa aparente e uma silhueta mais curta de maga de combate, mantendo chapéu pontudo violeta, roupa arcana e um único orbe de Lúmen no cajado. Evita cabelo longo prateado, túnica cerimonial comprida e sinos/carrilhão associados à referência de Sino.

Este conceito não altera ainda a ficha ou o contrato de Íris, nem substitui seu sprite runtime. Consulte [ficha](../../../02_heroes/hero_003_iris.md), [contrato](../../contracts/hero_iris.yaml) e [direção de modelos conceituais](../../CONCEPT_MODEL_STYLE.md).
