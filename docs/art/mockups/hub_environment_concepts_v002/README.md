# Pocket Hero — conceitos universais do Refúgio da Vigília

**Status:** CONCEPT — novas opções após a orientação de que o Hub não deve ter a árvore nem uma região específica como tema dominante. O Refúgio deve funcionar como base recorrente entre expedições em regiões distintas.

## Direção comum

Arquitetura neutra de pedra e madeira; os Lúmens aparecem como pequenos focos de luz/energia, não como tema visual dominante. A forja aparece primeiro; outras fachadas podem ser ativadas conforme os serviços forem desbloqueados. Caminhos e fundo podem variar sem redesenhar a identidade central do Hub.
