# Refúgio da Vigília — composição mobile retrato

**Status:** CONCEPT — estudo vertical de tela inteira baseado na referência selecionada em [v003](../hub_environment_concepts_v003/README.md).

A composição reorganiza a base para o viewport vertical do projeto: portão e rotas no topo, fachadas do Ferreiro e Alquimista no meio, caminho central livre e party descansando junto da fogueira na parte inferior. Usa Bastião, Flecha e Íris como guias de identidade; a produção deve reutilizar os sprites canônicos, não esta imagem.

[Ver conceito retrato](08_refugio_mobile_retrato.png)

O PNG é uma imagem conceitual contínua, não um atlas de tiles, sprite sheet, asset final ou Golden. Para a produção, redesenhar a cena em peças/quads modulares de cenário e props, dimensionadas para o viewport `432×960`, e criar sprite sheets de animação separados para os elementos que precisem se mover. Consultar [`HUB_VISUAL_DIRECTION.md`](../../../05_hub/HUB_VISUAL_DIRECTION.md) antes de produzir.
