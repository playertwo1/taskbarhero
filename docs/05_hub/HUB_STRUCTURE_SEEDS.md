# Refúgio da Vigília — estrutura proposta

**Origem:** seção HUB-1 do antigo `ROADMAP_EXPANSAO_CONTEUDO_POCKET_HERO.md`, movida para cá em 2026-09-29. Direção visual escolhida em [HUB_VISUAL_DIRECTION.md](HUB_VISUAL_DIRECTION.md); serviços dos artesãos em [CRAFT-1](../03_systems/EQUIPMENT_AND_CRAFTING_SYSTEM.md), que prevalece em conflito.

O Hub deve parecer uma cidade/refúgio reconstruída, não uma tela de seleção de sistemas.

## Núcleo inicial

- **Lanterna-Mãe:** progresso de capítulos, fragmentos recuperados, evolução visual do mundo, conexão com os Corações de Lúmen.
- **Mesa da Expedição:** montar party de 3, selecionar destino, preparar run, consultar modificadores da expedição.
- **Árvore dos Ecos:** progressão global, desbloqueios estruturais, sete ramos, Fragmentos de Ressonância ([fonte](../03_systems/GLOBAL_RESONANCE_TREE.md)).

## Estabelecimentos desbloqueáveis

| Local | Função |
| --- | --- |
| Ferraria | Ferreiro: equipamento, desmontagem, melhoria e reforja |
| Laboratório do Alquimista | transmutação, Essências, Catalisadores e conversões |
| Câmara/Arquivo de Ecos | Gravadora de Ecos: memórias, bestiário, Ecos e modificadores avançados |
| Ourivesaria | joias, acessórios e especialização fina |
| Jardim | ligado a Orvalho; função a validar |
| Memorial | bosses, feitos, campanha pessoal e história |
| Campo de Treino | teste de builds, dano, skills e combinações |

## Regra de desbloqueio

Sistemas aparecem gradualmente: recuperar mundo → Hub muda visualmente → novo serviço aparece → nova possibilidade de build. Evitar todos os menus desde o início.
